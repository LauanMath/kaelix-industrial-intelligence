# Gateway HTTP v1

Snapshot dos schemas e exemplos de `kaelix-firmware/docs/contracts/gateway-v1`,
importado em 11/10/2026 sem alterações. A referência de origem é o contrato do C3.
Os DTOs em `packages/contracts` e os endpoints em `apps/server` seguem esta versão.

O contrato original descreve o significado de cada campo e o tratamento pelo C3.
O [guia da API](../../../apps/server/README.md) documenta persistência, autenticação,
execução e a política de sessões de heartbeat do servidor.

Ao evoluir a fronteira do firmware/API, atualizar ambos os repositórios e executar
os testes com as fixtures e schemas desta pasta. Os exemplos são fixtures técnicas;
não representam credenciais ou uma integração física já validada.
